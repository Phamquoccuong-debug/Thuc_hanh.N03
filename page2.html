GitHub là gì?

Nền tảng lưu trữ mã nguồn dùng Git, giúp lập trình viên làm việc nhóm và quản lý phiên bản.

Repository

Kho chứa toàn bộ mã nguồn và lịch sử thay đổi của dự án.

Commit

Một lần lưu thay đổi, kèm thông điệp mô tả đã sửa gì.

Branch

Nhánh làm việc riêng để phát triển tính năng mà không ảnh hưởng nhánh chính.

Pull Request

Đề nghị gộp code từ nhánh này sang nhánh khác, để cả nhóm review.

GitHub Actions

Tự động build, test, deploy mỗi khi push code — nền tảng CI/CD.

GitHub Pages

Host website tĩnh miễn phí — chính là trang bạn đang xem!
